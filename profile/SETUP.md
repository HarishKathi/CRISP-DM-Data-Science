# Publishing the GitHub profile README

GitHub shows a README on your profile page only when it lives in a public
repository named exactly after your username.

1. Go to https://github.com/new and create a **public** repository named `HarishKathi`
   (GitHub will say "You found a secret!"). Tick "Add a README file".
2. Replace that README's content with `profile/README.md` from this folder.
3. Fill in the placeholders:
   - `YOUR-LINKEDIN` → your LinkedIn profile slug
   - `YOUR-EMAIL@example.com` → the email you want public (or delete the Email badge)
   - "Currently working on / learning" lines
   - The two *Your next project* rows in Featured Projects
   - Remove any tech badges you don't use (R, Tableau, …)
4. Commit. Your profile at https://github.com/HarishKathi now shows it.

## Other profile polish
- Upload a professional photo, and set name, bio, location and LinkedIn link under Settings → Public profile.
- Pin your 4–6 best repositories (Profile → Customize your pins).
- Give each pinned repo a clear description, topics (e.g. `data-science`, `eda`, `crisp-dm`) and a README with problem, approach, results.
